# SkillPilots Day 21 — Delete Note Feature

Front-end recreation of the supplied Career Path screenshot.

## Task shown
1. Add a Delete button inside each note card's HTML.
2. Attach a click listener that sends a DELETE request to `/api/notes/{id}`.
3. On success, remove the card element from the DOM.
4. Update the backend to return appropriate status codes for delete operations.

## Files
- `index.html` — Career Path page and implementation steps modal
- `style.css` — styling and responsive layout
- `script.js` — modal open/close interactions

## Run in VS Code
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser, or install Live Server.
4. Right-click `index.html` and choose **Open with Live Server**.

**Note:** This is a front-end recreation based on the screenshot, not the original SkillPilots source code. It does not include the real site's backend, database, authentication, or API. The submit button is a demo only.
